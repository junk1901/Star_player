OWNER가 검토할 최종 수용 확인서를 초안으로 작성한다.
확인서에서는 다음을 구분한다.

* B1 코드 구현 수용
* Codex T11 검수 완료
* 운영 Gate 미완료
* Official Execution 미허가
* Phase 3 미완료

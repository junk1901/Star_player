Star Player B1 — D3 기준본 복구 및 T11 재검수 준비
OWNER 결정
기존 NSC-6 결정 근거 SHA를 유지하는 복원 방식을 채택한다.
현재 TASK.md의 SHA에 맞춰 승인 기준 목록을 수정하는 것은 허가하지 않는다.
1. D3 복구
현재 TASK.md를 덮어쓰기 전에 원본 바이트 그대로 별도 작업 지시 보관 파일에 저장하고 SHA를 기록한다.
다음으로 승인 당시 TASK.md의 정확한 원본을 찾는다.
기존 승인 SHA-256:
ecbc0859c809c68151c93f92058c31a7ab0b84ce8d8cc9a4a25512b7dd06f825
확인된 원본에서만 TASK.md를 복원한다.
복원 후:

* TASK.md SHA 일치 확인
* 승인 계약 SHA 확인
* 승인 보존본 SHA 확인
* PDF 두 개 SHA 확인
* B1-T00_BASELINE.sha256 변경 없음 확인
* tools/verify.ps1 전체 실행
* 최종 Git 상태 기록

원본을 확보하지 못했다면 내용을 재작성하여 SHA를 맞추려 하지 않는다. 승인 기준 변경을 임의로 진행하지 말고 정확한 차단 사유를 보고한다.
앞으로 TASK.md를 일회성 개발 지시서로 교체하지 않는다. 새 작업 지시는 별도 docs/tasks/ 경로나 Claude Code 채팅으로 관리한다.

B1-T11-01~08 수정 결과를 유지한다.
기존에 구현한 수정 사항을 처음부터 다시 작성하지 않는다.

* 신규 테스트 전체

* 현재 구현

# ADR-001 — Project boundaries and desktop export baseline (Phase 0)

- Status: Accepted — Phase 0 approved 2026-10-10 (GPT Chat final review relayed by the owner; Codex re-review of the post-review amendments `미실시`)
- Date: 2026-10-10
- Scope: confirms ROADMAP §1.2 / §2 structure after it was built, exported and run. No product rule changed.

## Decisions

1. **Layers and references** follow ROADMAP §1.2 exactly: Domain (no references) ← Simulation ← Application (owns ports) ← Infrastructure (SQLite adapter); the Godot client references **Application and Infrastructure only** (no Domain/Simulation, amended after the Codex review), and only `game/Bootstrap` names Infrastructure types. Presenters receive Application DTOs (`DiagnosticReport`, `BuildInfo`); Application contracts do not expose Domain types such as `Result<T>` to the client. Enforced by `tests/StarPlayer.Application.Tests/ArchitectureTests.cs` using the real `.csproj` files, compiled assembly references (including the compiled `StarPlayer.Client.dll`, which catches a Domain type used without naming its namespace) and client sources; the detectors are themselves tested and were mutation-checked. Simulation determinism is guarded by the `SourceScan` rules in `SimulationDeterminismTests`.
2. **Toolchain:** .NET SDK 8.0.425 (`rollForward: disable`) with Godot 4.7.2 stable Mono and `Microsoft.Data.Sqlite` 8.0.31. See `docs/toolchain.md`.
3. **Two solution files.** Root `StarPlayer.sln` holds all projects. Godot's export plugin looks for `<dotnet/project/assembly_name>.sln` beside the project and refuses to export C# otherwise ("A solution file is required for projects with C# files"), so `game/StarPlayer.Client.sln` contains only the client project; its project references pull in the rest. Both are committed.
4. **Core diagnostics live in Infrastructure, not in the client.** `SqliteStorageDiagnostics` implements the Application port `IStorageDiagnostics`; the same code runs under xUnit, Godot headless and the exported program, so the export probe exercises the real packaged provider.
5. **Diagnostic launch mode.** Arguments after `--` (`--diagnostics`, `--diagnostics-out=`, `--screenshot=`) make the shell run the probe unattended and exit 0/1. The client reads both `OS.GetCmdlineArgs()` and `OS.GetCmdlineUserArgs()` (in a headless editor run only the latter contains them).
6. **SQLite connection policy for the probe:** `Pooling=False` (so temporary files can be deleted on Windows) and `Foreign Keys=True` set explicitly on every connection. Observed provider default with this bundled SQLite (3.53.3) was `foreign_keys=1`, but production code must not rely on that.
7. **Build configurations.** Both solutions map `Release`→`Release` and `Debug`→`Debug`. Godot uses `Debug` in the editor and publishes `ExportRelease`; the Godot solution also lists `ExportDebug`/`ExportRelease`. `Application.Tests` builds the client with `ReferenceOutputAssembly=false` (build order only) so the compiled-reference test always sees a fresh DLL in the same configuration.
8. **Export templates are verified, not assumed.** `tools/install-export-templates.ps1` restores them from the SHA-512-verified official `.tpz`; `verify.ps1` compares SHA-256 of the five installed files and reports missing templates as INCOMPLETE.

## Export result (evidence in `docs/reports/PHASE_0_VERIFY_LOG.md`)

Windows x86_64 release export produced `StarPlayer.exe`, `StarPlayer.pck`, `StarPlayer.console.exe` and a data folder containing the managed assemblies and native `e_sqlite3.dll`. A copy placed in a fresh temp folder opened the shell at 2560×1440 and reported 8/8 SQLite steps passed (commit, rollback, FK on two connections, backup, backup reopen). Native SQLite packaging therefore needs no manual step in Phase 0.

## Consequences / follow-ups

- Later phases that add a database schema must go through Application ports and keep `Foreign Keys=True` explicit.
- Export size is ~110 MB exe + .NET runtime folder; no trimming/single-file work was attempted (Phase 29 concern).
- `rcedit`/icon/version resources, code signing and a bundled Korean font are not done (`docs/toolchain.md`).

### 7.2 Other facts found while reviewing the working tree

- `Star/환영합니다!.md` (Obsidian welcome note) shows as deleted in `git status`. Claude Code did not delete it; it was left as found for the owner to decide.
- Godot generates `*.cs.uid` files beside scripts; they are intentionally kept as commit candidates.
- Nothing was committed or pushed.
- **A defect in the new `verify.ps1` checks was found and fixed during remediation.** The first run with the new B3/E1b checks passed only because the sources had just changed; a second run failed (`Release client output was not produced by this build`, `ExportRelease publish output is older than this run`) because incremental builds leave an up-to-date DLL untouched. That was a wrong freshness criterion in the check, not a product failure. The criterion is now "output not older than its client sources", "Debug output not rewritten by the Release build", "export folder recreated this run", and "exported client DLL identical to the ExportRelease output and different from Debug". After the fix `verify.ps1` passed twice in a row (exit 0). The failed intermediate run is not part of the preserved logs (the log is overwritten per run); it is recorded here.
